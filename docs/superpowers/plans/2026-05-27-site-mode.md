# Site Mode Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add `VITE_TYPE_SYSTEM=site` with a public commercial website and a protected `/admin` content manager.

**Architecture:** Keep site mode isolated from stock, fleet, and manager workflows. Add independent Prisma models and `/site` routes, then branch the React router and shell navigation for public site and site-admin experiences.

**Tech Stack:** Express, Prisma, SQLite, Vitest, React, React Router, Tailwind, shadcn-style local components, lucide-react.
